## 📌 팀 협업 소스트리 규칙

형상관리자: 김보현

---

### 1. 매일 아침 작업 전 main 브랜치에서 pull 먼저!

### 2. 브랜치 구조
- `main` ← 마치기 전 형상관리자가 merge
- `develop` ← 각자 작업 후 직접 merge 가능
- `user/본인이름` ← 여기서 작업 후 develop으로

### 3. 커밋 메시지 규칙
- `feat` : 새 기능 추가
- `fix` : 코드, 파일 수정
- `upload` : 파일 업로드, 추가
- `test` : 테스트 코드
- `docs` : 문서, 주석

### 4. main 직접 push 금지
develop → main 은 형상관리자만 처리
